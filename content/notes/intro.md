## 数据结构的基本概念

### 数据、数据元素与数据项

| 概念 | 复习时抓住的含义 | 学生成绩表中的例子 |
| --- | --- | --- |
| 数据 | 可被计算机处理的信息的符号表示 | 学号、姓名、分数等信息 |
| 数据元素 | 数据的基本单位，通常作为一个整体考虑和处理 | 一名学生的一条完整记录 |
| 数据项 | 构成数据元素的更细的单位，通常作为数据的不可分割的最小单位 | 学号、姓名、某科成绩 |
| 数据对象 | 性质相同的数据元素的集合，是数据的一个子集 | 某班全体学生的记录集合 |
| 数据结构 | 数据元素以及元素之间的关系 | 按学号顺序组织的学生记录及其前后关系 |

```cpp
typedef struct {
    int id;
    int score;
} Student;
```

这里一条 `Student` 记录对应一个数据元素，`id` 和 `score` 对应数据项。

**考点：数据对象与数据结构的区别。** “这些元素具有相同性质”强调集合；“这些元素之间有什么关系”才涉及结构。只有一组学生记录，尚不能由此确定它是线性关系、树形关系还是其他关系。

**易错点：** 数据元素是结构中研究的基本单位；数据项是构成元素的更细单位。不要把“基本单位”和“最小单位”混为一谈。

### 数据结构的形式表示

通常用二元组表示：

$$
\text{Data Structure}=(D,R)
$$

- $D$：数据元素的有限集合。
- $R$：数据元素之间的关系集合。

例如：

$$
D=\{a,b,c\},\qquad R=\{\langle a,b\rangle,\langle b,c\rangle\}
$$

若关系表示直接前后次序，就描述了序列 $a\to b\to c$ 的逻辑关系。

**考点：** 关系描述的是逻辑联系，并不直接规定元素在内存中放在哪里，也不要求用指针表示。

### 数据结构三要素

| 要素 | 回答的问题 | 例子 |
| --- | --- | --- |
| 逻辑结构 | 元素之间有什么关系？ | 线性表中元素有确定的先后次序 |
| 存储结构 | 元素及其关系怎样在计算机中表示？ | 顺序表用连续存储单元，链表用链接表示联系 |
| 数据的运算 | 要对数据做什么操作？ | 插入、删除、查找、修改、遍历 |

运算要区分**定义**和**实现**：定义描述输入、输出及操作效果；实现需要结合具体存储结构设计算法。

**记忆关系：** 逻辑结构给出关系，存储结构落实表示，运算在具体表示上执行。

## 逻辑结构

### 四类逻辑结构

| 类别 | 元素之间的主要关系 | 识别依据 |
| --- | --- | --- |
| 集合 | 除同属一个集合外，没有进一步规定的关系 | 不强调次序、层次或连接关系 |
| 线性结构 | 一对一 | 非空线性结构有唯一的首、尾元素；其余元素各有唯一直接前驱和直接后继 |
| 树形结构 | 一对多 | 有层次关系；通常一个结点可有多个孩子，非根结点有唯一父结点 |
| 图状或网状结构 | 多对多 | 一个结点可与多个其他结点发生联系 |

集合、树和图属于非线性结构。线性表、栈、队列属于线性结构；栈和队列对可执行的操作施加了限制，但元素间仍是线性关系。

**边界：** 空表和只有一个元素的表也可以是线性表；不能因为没有明显的前驱、后继就把它们排除。

### 前驱后继与物理相邻

“前驱、后继”描述的是逻辑关系。“地址相邻”描述的是物理存储。

- 顺序存储的线性表：逻辑相邻通常由物理相邻体现。
- 链式存储的线性表：逻辑相邻由链接体现，地址可以不连续。

**易错点：** 不能从“某元素存储在另一个元素旁边”直接推出二者具有前驱、后继关系；判断关系要结合采用的表示规则。

### 结构分类的常见判断

- 单链表、双链表、循环链表描述的是线性表的具体存储组织，双向指针不会把逻辑结构变成“多对多”。
- 二叉树每个结点最多有两个孩子，仍属于树形结构。
- 二维数组的二维下标反映按多个维度定位元素的方式，不能直接据此判断为树或图。
- 判断“线性还是非线性”应看研究对象的逻辑关系；判断“顺序还是链式”应看存储表示。

## 存储结构

### 顺序存储

把逻辑上相邻的元素存放在物理上相邻的存储单元中。在线性表的常见表示中，元素等长时可用首地址和下标计算地址。

若每个元素占 $L$ 个存储单元，下标从 $0$ 开始：

$$
\operatorname{LOC}(a_i)=\operatorname{LOC}(a_0)+iL
$$

**典型特点：** 支持按下标随机访问；通常需要一段连续空间。中间位置的插入、删除通常需要移动元素，具体代价还要看位置和实现。

### 链式存储

元素存放在结点中，通过指针或其他链接信息表示关系。结点在内存中的位置可以不连续。

```cpp
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

`data` 是数据域，`next` 是链接信息。`next` 所保存的联系属于存储表示，不改变线性表的逻辑关系。

**典型特点：** 需要额外的链接空间；一般不能直接按逻辑序号随机访问。已知适当结点位置时，某些插入、删除可以通过少量链接修改完成。

**易错点：** “链表插入、删除是 $O(1)$”需要限定前提。若先要按序号找到结点，查找位置本身可能是 $O(n)$。

### 索引存储

在存储元素信息之外，建立索引表，记录用于定位元素的索引信息，例如关键字与存储位置的对应关系。

**抓住两点：** 索引是辅助定位结构；它需要额外空间，并有建立和维护的代价。索引的具体组织方式影响查找效率。

### 散列存储

根据元素的关键字，通过散列函数计算存储位置。

$$
\text{位置}=h(\text{关键字})
$$

**考点：** 不同关键字可能得到相同位置，即发生冲突。散列不是“任何情况下都能一步查到”，实际代价受散列函数、冲突处理和装填情况影响。

### 逻辑结构与存储结构的关系

| 判断 | 结论与理由 |
| --- | --- |
| 同一种逻辑结构能否有多种存储结构？ | 能。例如线性表可以顺序存储，也可以链式存储 |
| 逻辑结构是否依赖元素的具体内存地址？ | 不依赖。逻辑结构研究元素关系 |
| 存储结构是否需要表示元素之间的关系？ | 需要。既要保存元素信息，也要体现相应关系 |
| 同一种存储手段是否只能用于一种逻辑结构？ | 不是。数组和链接都能用于多种逻辑结构的表示 |
| 运算的算法是否与存储结构无关？ | 不是。同一个操作在不同存储结构上的实现和代价可能不同 |

**容易混淆的两组词：**

- 静态分配、动态分配描述内存分配方式；顺序存储、链式存储描述元素及关系的存储表示。二者不能简单一一对应。
- 用动态分配获得一段连续数组，仍可实现顺序存储；用数组下标模拟链接，可以实现静态链表。

## 数据运算、数据类型与抽象数据类型

### 运算的定义和实现

以“按序号删除线性表中的元素”为例：

- **定义：** 给定一个合法序号，删除该元素，剩余元素的相对次序保持不变。
- **顺序表实现：** 后续元素前移，长度减一。
- **链表实现：** 修改适当链接，必要时释放结点。

操作效果可以相同，实现步骤和效率却不同。基本操作设计时要明确参数含义、合法范围、返回结果以及是否修改原结构。

### 数据类型

数据类型由**值的集合**及在这些值上定义的**操作集合**组成。

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 原子类型 | 值不可再分解为该类型层面的组成部分 | 整型及其相应运算 |
| 结构类型 | 值由若干成分按某种结构组成 | 数组、记录及其相应运算 |

只给出一组可能取值，却没有讨论能执行哪些操作，尚未完整描述一个数据类型。

### 抽象数据类型

抽象数据类型（ADT）从逻辑层面描述数据及其关系，并规定允许的操作，屏蔽具体实现细节。

常见形式：

$$
\mathrm{ADT}=(D,S,P)
$$

- $D$：数据对象。
- $S$：数据关系。
- $P$：基本操作。

例如“栈”规定后进先出的操作规则。使用者需要知道入栈、出栈的作用和约束，不必据此确定底层使用数组还是链表。

**考点：** ADT 描述“是什么、能做什么”；具体数据结构实现进一步回答“怎样存储、怎样完成操作”。ADT 不要求必须用 C++ 的类来表达。

## 算法的基本概念

### 算法与程序

算法是解决特定问题的一组明确、有限的操作步骤。

- 算法可以用自然语言、流程图、伪代码或程序语言描述。
- 程序是用程序设计语言表达并可在计算机上执行的代码。
- 为了长期提供服务而持续运行的程序，不必表现为一个有限步骤后整体终止的算法过程。程序和算法的概念不能直接画等号。

### 算法的五个特性

| 特性 | 准确理解 | 常见误判 |
| --- | --- | --- |
| 有穷性 | 对合法输入执行有限步骤，并在有限时间内结束 | 运行很慢不等于没有有穷性；无限循环才是明确的问题 |
| 确定性 | 每一步含义明确，不产生歧义 | “随便取一个合适的数”若没有明确规则，不能作为严格步骤 |
| 可行性 | 每一步都能通过可执行的基本操作在有限时间内完成 | “一步求出任意方程的全部解”未说明可执行方法 |
| 输入 | 可以有零个或多个输入 | 算法不一定必须从键盘接收输入 |
| 输出 | 至少有一个输出结果 | 结果可通过返回值、输出参数、修改后的状态等体现，不一定打印 |

**区分：** 有穷性关注整个过程是否终止；可行性关注每一步能否执行。正确性是算法设计应满足的要求，不能直接替换“五个特性”中的某一项。

### 好算法的设计要求

| 要求 | 复习时应会说明的内容 |
| --- | --- |
| 正确性 | 对规定的合法输入产生符合问题要求的结果 |
| 可读性 | 逻辑清楚，便于理解、检查和维护 |
| 健壮性 | 对不合法输入作合理处理，而不是产生失控行为或难以理解的结果 |
| 效率与存储需求 | 在规定问题和条件下，合理控制时间和空间开销 |

正确性是前提；评价效率时要在相同的问题要求和分析口径下比较。时间更省与空间更省之间可能存在取舍。

### 函数示例与接口约定

```cpp
// 前置条件：n >= 0；n > 0 时 a 指向至少 n 个有效元素。
// 返回第一次出现 key 的下标；找不到时返回 -1。
// 不修改 a；下标从 0 开始。
int FindFirst(const int a[], int n, int key) {
    for (int i = 0; i < n; ++i) {
        if (a[i] == key) {
            return i;
        }
    }
    return -1;
}
```

**接口复习要点：** 数组下标与线性表的逻辑位序可能采用不同起点，必须说明。`-1` 在本例中代表失败；其他函数可以使用不同约定，但应前后一致。

**边界检查：** 空数组时直接返回 `-1`；重复元素时返回首次出现的位置；失败时不访问数组以外的位置。

## 算法效率的度量

### 事后统计与事前分析

- **事后统计：** 实际运行程序，测量耗时。结果受硬件、编译环境、输入数据等因素影响。
- **事前分析：** 建立计算模型，分析操作次数随问题规模的增长规律。考试中的复杂度分析主要采用这种方法。

渐近复杂度用于比较增长趋势，不能保证同阶算法耗时完全相同，也不能保证较低阶算法在所有小规模输入上更快。

### 问题规模与基本操作

问题规模是描述输入大小的参数，不一定永远是数组长度。

| 问题 | 常见规模参数 |
| --- | --- |
| 线性表上的查找 | 元素个数 $n$ |
| 矩阵操作 | 行数与列数 $m,n$ |
| 图算法 | 顶点数 $V$、边数 $E$ |

若操作 $i$ 执行 $f_i(n)$ 次，每次耗时视为常数 $t_i$，则可写成：

$$
T(n)=\sum_i t_i f_i(n)
$$

考试中通常选择主导增长的基本操作，先算其频度，再取增长阶。若题目要求某条语句的**精确执行次数**，则必须保留下标边界和常数，不能只写复杂度。

**本页代码的分析约定：** 基本整数运算、下标访问、指针操作等按常数时间处理；整数范围视为足够大。用于计数的 `long long` 在真实机器上仍有上限，分析阶数时不以机器溢出改变算法含义。

## 时间复杂度

### 大O、紧确阶与增长趋势

大 $O$ 表示渐近上界。对最终为正的 $g(n)$，若存在常数 $c>0$ 和 $n_0$，使得：

$$
0\le T(n)\le c g(n),\qquad n\ge n_0
$$

则 $T(n)=O(g(n))$。

同理，$\Omega(g(n))$ 表示渐近下界；同时有对应上、下界时，用 $\Theta(g(n))$ 表示紧确增长阶。这里区分上界和紧确阶，是为了避免误判选择题。[渐近上界的概念说明](https://opendsa-server.cs.vt.edu/ODSA/Books/Catalog/html/AnalAsymptotic.html)

例如：

$$
T(n)=3n^2+5n+8=\Theta(n^2)
$$

写成 $O(n^2)$ 正确，写成 $O(n^3)$ 从“上界”定义看也正确；若题目要求最贴近的复杂度，应选 $n^2$ 阶。

**考点：** 大 $O$ 本身不等于“最坏情况”。最好、平均、最坏情况的函数，都可以各自用大 $O$ 表示上界。

### 化简规则与常见阶

求增长阶时：

1. 忽略非零常数因子。
2. 忽略低阶项。
3. 常量操作记作 $O(1)$。
4. 对固定底数 $b>1$，$\log_b n$ 的底数只影响常数因子。

常见增长顺序：

$$
1<\log n<\sqrt n<n<n\log n<n^2<n^3<2^n<n!
$$

以上是 $n$ 足够大时的增长趋势，不是对每个小整数都严格成立的数值不等式。

**易错点：** $2^n$ 与 $3^n$ 不是同阶。对数换底产生常数因子，指数换底通常不会。

### 顺序、分支与嵌套

**顺序执行：** 固定个数的代码段相加，取主导阶。

$$
O(f(n))+O(g(n))=O(\max\{f(n),g(n)\})
$$

**分支执行：** 若问最坏时间，比较可达分支的最大代价，并计入条件判断代价；若问平均时间，需要分支发生概率。

**嵌套执行：** 对每次外层迭代累加内层代价。

$$
T(n)=\sum_{i\in\text{外层迭代}}\text{第 }i\text{ 次内层代价}
$$

只有内层次数可按统一界估计时，才方便使用乘法。不能看到两层循环就直接写 $O(n^2)$。

## 最好、最坏与平均情况

### 三种分析口径

设 $I_n$ 为所有规模为 $n$ 的合法输入，输入 $x$ 的运行代价为 $T(x)$。

$$
T_{\mathrm{best}}(n)=\min_{x\in I_n}T(x),\qquad
T_{\mathrm{worst}}(n)=\max_{x\in I_n}T(x)
$$

若已给出输入分布：

$$
T_{\mathrm{avg}}(n)=\sum_{x\in I_n}P(x)T(x)
$$

最好、最坏是在**相同规模**下比较不同输入；平均是在给定分布下求期望。概率模型是平均分析的一部分。[三种情况的分析说明](https://opendsa-server.cs.vt.edu/ODSA/Books/Catalog/html/AnalCases.html)

### 顺序查找的典型计算

使用前面的 `FindFirst`，以关键字比较次数为基本操作，设 $n\ge1$。

| 情况 | 比较次数 | 增长阶 |
| --- | --- | --- |
| 第一个位置命中 | $1$ | 最好 $\Theta(1)$ |
| 最后一个位置命中 | $n$ | 最坏 $\Theta(n)$ |
| 查找失败 | $n$ | $\Theta(n)$ |
| 成功且目标等概率出现在任一位置 | $(n+1)/2$ | 平均 $\Theta(n)$ |

成功查找的平均比较次数：

$$
\frac1n\sum_{i=1}^{n}i=\frac{n+1}{2}
$$

若成功概率为 $p$，成功时位置仍等概率，失败代价为 $n$，则：

$$
\mathbb E[C]=p\frac{n+1}{2}+(1-p)n
$$

**考点提示：** 先读清题目是成功查找、失败查找，还是二者混合；“等概率”指哪些事件也要明确。

**易错点：** 平均代价不是一般意义上的“最好与最坏相加除以二”。本例成功查找恰好得到这个数值，是位置等概率和等差求和共同造成的。

### 未特别说明时的复习口径

408 常见题目中，“算法的时间复杂度”未另作说明时通常按最坏情况理解；题目明确给出最好、平均、成功、失败或特定输入时，按题目条件分析。

先确定输入类型，再计算次数，最后取阶。不要把“平均情况”理解成任选一个看起来普通的输入。

## 循环复杂度的典型例题

### 常数次与线性扫描

```cpp
// 条件：n >= 1，a 指向至少 n 个元素。
int ReadFirst(const int a[], int n) {
    return a[0];
}

// 条件：n >= 0，a 指向相应有效区间。
long long SumArray(const int a[], int n) {
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}
```

- `ReadFirst` 的操作次数不随 $n$ 增长：$\Theta(1)$。
- `SumArray` 的累加语句执行 $n$ 次：$\Theta(n)$。
- 两者辅助空间均为 $\Theta(1)$；数组参数本身不会复制整段输入数组。

### 三角形嵌套循环

```cpp
// 条件：n >= 0；count 统计 count++ 的执行次数。
long long CountPairs(int n) {
    long long count = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            ++count;
        }
    }
    return count;
}
```

第 $i$ 次外层迭代，内层执行 $i$ 次：

$$
\sum_{i=0}^{n-1}i=\frac{n(n-1)}2
$$

时间为 $\Theta(n^2)$，辅助空间为 $\Theta(1)$。

**易错点：** 内层不能统一写成执行 $n$ 次；虽然这样可估计出同一上界，但得不到精确频度。

### 倍增或折半循环

```cpp
// 条件：n >= 0。
int CountHalvings(int n) {
    int count = 0;
    while (n > 1) {
        n /= 2;
        ++count;
    }
    return count;
}
```

对 $n\ge1$，循环执行 $\lfloor\log_2n\rfloor$ 次。因为每次将规模除以 $2$，经过 $k$ 次后规模约为 $n/2^k$，达到常量规模时 $k=\Theta(\log n)$。

**迁移：** `i *= 2`、`i *= 3` 或规模每次除以固定常数 $b>1$，通常也是对数次。实际编码时，倍增变量要注意整数溢出。

### 线性外层与对数内层

```cpp
// 条件：n >= 0。
long long CountRepeatedHalvings(int n) {
    long long count = 0;
    for (int i = 0; i < n; ++i) {
        int j = n;                 // 每轮外层都会重新赋值
        while (j > 1) {
            j /= 2;
            ++count;
        }
    }
    return count;
}
```

基本操作频度为 $n\lfloor\log_2n\rfloor$，时间为 $\Theta(n\log n)$。

**判断关键：** `j` 在外层循环内部重新初始化，每轮都完整执行对数次内层循环。

### 几何级数型嵌套

```cpp
// 条件：n >= 1；理论计数时假定整数范围足够。
long long CountGeometricBlocks(int n) {
    long long count = 0;
    long long size = 1;
    while (size <= n) {
        for (long long j = 0; j < size; ++j) {
            ++count;
        }
        size *= 2;
    }
    return count;
}
```

外层共 $\lfloor\log_2n\rfloor+1$ 次，但各轮内层次数是 $1,2,4,\ldots$。

令 $k=\lfloor\log_2n\rfloor$：

$$
C(n)=1+2+\cdots+2^k=2^{k+1}-1=\Theta(n)
$$

**易错点：** 不能用“外层 $\log n$，内层最大 $n$”直接断言紧确阶为 $n\log n$。这样只得到较松的上界。

### 共享变量型嵌套

```cpp
// 条件：n >= 0。
long long CountSharedProgress(int n) {
    long long count = 0;
    int j = 0;                     // 只初始化一次
    for (int i = 0; i < n; ++i) {
        while (j < n) {
            ++j;
            ++count;
        }
    }
    return count;
}
```

`j` 只从 $0$ 增长到 $n$ 一次，`++count` 总共执行 $n$ 次。计入外层循环本身，总时间仍为 $\Theta(n)$。

**判断关键：** 内层进度没有在每轮外层重新开始。两层循环的书写形式不决定二次复杂度。

### 累加达到阈值

```cpp
// 条件：n >= 1。
long long StepsToReach(long long n) {
    long long step = 0;
    long long total = 0;
    while (total < n) {
        ++step;
        total += step;
    }
    return step;
}
```

运行 $k$ 次后：

$$
\text{total}=1+2+\cdots+k=\frac{k(k+1)}2
$$

达到 $n$ 所需的最小 $k$ 为：

$$
k=\left\lceil\frac{\sqrt{1+8n}-1}{2}\right\rceil
=\Theta(\sqrt n)
$$

**方法：** 先写循环变量经过 $k$ 次迭代后的表达式，再根据终止条件反解 $k$。

### 内层次数随外层取对数

若第 $i$ 轮内层执行 $\Theta(\log i)$ 次，外层 $i=1,2,\ldots,n$，则：

$$
T(n)=\sum_{i=1}^n\Theta(\log i)=\Theta(n\log n)
$$

上界：每项不超过常数倍的 $\log n$。下界：后半段至少有约 $n/2$ 项，每项至少为常数倍的 $\log(n/2)$。因此上、下界同阶。

**考点：** 不会求精确和式时，可用上下界夹住增长阶。

## 递归复杂度

### 递归分析的三个问题

1. 一次调用产生多少个子调用？
2. 子问题的规模怎样变化？
3. 除子调用之外，本层还做多少工作？

时间分析要统计整个递归展开过程中的工作。空间分析要统计同一时刻尚未返回的调用及其占用空间。

### 每次减少一个元素

```cpp
// 条件：n >= 0；a 指向相应有效区间。
long long SumRecursive(const int a[], int n) {
    if (n == 0) {
        return 0;
    }
    return SumRecursive(a, n - 1) + a[n - 1];
}
```

$$
T(n)=T(n-1)+\Theta(1)=\Theta(n)
$$

最大调用深度为 $n+1$，每层保存常数个参数和局部状态，辅助空间为 $\Theta(n)$。

**易错点：** 没有显式申请数组，不代表辅助空间为常数；递归调用栈也占空间。

### 每次规模折半

```cpp
// 条件：n >= 1。
int HalvingDepth(int n) {
    if (n <= 1) {
        return 0;
    }
    return 1 + HalvingDepth(n / 2);
}
```

$$
T(n)=T(\lfloor n/2\rfloor)+\Theta(1)=\Theta(\log n)
$$

每层常数空间，调用深度 $\Theta(\log n)$，辅助空间为 $\Theta(\log n)$。

循环版 `CountHalvings` 与此例有同阶时间，但循环版辅助空间为 $\Theta(1)$。

### 两个减一子调用

```cpp
// 条件：n >= 0；用于展示重复递归的代价。
long long CountBinaryRecursion(int n) {
    if (n == 0) {
        return 1;
    }
    long long left = CountBinaryRecursion(n - 1);
    long long right = CountBinaryRecursion(n - 1);
    return left + right + 1;
}
```

$$
T(n)=2T(n-1)+\Theta(1)=\Theta(2^n)
$$

展开树第 $k$ 层有 $2^k$ 个调用，总调用数为 $2^{n+1}-1$。但左右子调用依次执行，同一时刻只有一条活动调用路径，辅助空间为 $\Theta(n)$。

**考点：** 递归总调用次数决定时间中的主要工作量；最大同时活动的调用链决定调用栈空间。二者不要混淆。

### 两个折半子调用

若递推关系为：

$$
T(n)=2T(n/2)+\Theta(1)
$$

并在常量规模终止，则在 $n=2^k$ 时展开树有约 $n$ 个叶子，总调用数为 $\Theta(n)$，因此时间为 $\Theta(n)$。各层只用常数局部空间、子调用依次执行时，栈空间为 $\Theta(\log n)$。

如果每层还需要处理当前问题规模对应的 $\Theta(n)$ 工作，递推式就变为：

$$
T(n)=2T(n/2)+\Theta(n)=\Theta(n\log n)
$$

此时展开树有 $\Theta(\log n)$ 层，每层总工作量 $\Theta(n)$。

### 常见递推式对照

| 递推式 | 时间阶 | 分析切入点 |
| --- | --- | --- |
| $T(n)=T(n-1)+\Theta(1)$ | $\Theta(n)$ | $n$ 层，每层常量工作 |
| $T(n)=T(n-1)+\Theta(n)$ | $\Theta(n^2)$ | $n+(n-1)+\cdots+1$ |
| $T(n)=T(n/2)+\Theta(1)$ | $\Theta(\log n)$ | 规模连续折半 |
| $T(n)=T(n/2)+\Theta(n)$ | $\Theta(n)$ | $n+n/2+n/4+\cdots$ |
| $T(n)=2T(n/2)+\Theta(1)$ | $\Theta(n)$ | 整棵树的结点数 |
| $T(n)=2T(n/2)+\Theta(n)$ | $\Theta(n\log n)$ | 每层线性工作，共对数层 |
| $T(n)=2T(n-1)+\Theta(1)$ | $\Theta(2^n)$ | 每层分支翻倍，深度线性 |

表中默认常量规模终止，取整不影响所列增长阶。这些是复杂度识别补充，不必为绪论引入完整的主定理。

## 空间复杂度

### 总空间与辅助空间

算法占用的空间可以包括输入数据、输出数据、额外工作空间和调用栈。408 常见算法题通常重点分析**辅助空间**；若题目明确要求总空间或包括输出空间，应按题目口径计算。

- 输入数组有 $n$ 个元素，不代表使用它的每个算法都需要 $\Theta(n)$ 辅助空间。
- 只声明若干与 $n$ 无关的变量，通常是 $\Theta(1)$ 辅助空间。
- 新建长度随 $n$ 增长的数组，通常是 $\Theta(n)$ 辅助空间。
- 递归需计入同时活动的调用栈。

空间取的是执行过程中**同时占用的峰值**，不能把已经释放、之后重复使用的空间逐次相加。

### 原地逆置示例

```cpp
// 条件：n >= 0；a 指向相应有效区间。
// 直接修改原数组。
void ReverseInPlace(int a[], int n) {
    int left = 0;
    int right = n - 1;
    while (left < right) {
        int temp = a[left];
        a[left] = a[right];
        a[right] = temp;
        ++left;
        --right;
    }
}
```

循环执行 $\lfloor n/2\rfloor$ 次，时间为 $\Theta(n)$；额外变量个数固定，辅助空间为 $\Theta(1)$。

就地工作（原地算法）的常见考试口径是辅助空间为 $O(1)$。不修改输入并不自动意味着空间大；修改输入也不自动意味着原地。

### 数组、指针与空间计数

| 情形 | 应如何计空间 |
| --- | --- |
| 用数组参数接收已有输入 | 参数保存指针，通常没有复制整个数组 |
| 一个指针指向新申请的 $n$ 个元素 | 指针本身是常量空间，申请的存储区是 $\Theta(n)$ |
| 一块真正与 $n$ 无关的固定长度工作数组 | 按随 $n$ 的增长来看是 $\Theta(1)$ |
| 工作数组容量随着问题规模增长 | 按容量计数，例如 $\Theta(n)$ |
| 各轮申请常量空间且及时释放 | 峰值可为 $\Theta(1)$，不是轮数乘常量 |
| 递归每层常量空间，最大深度为 $d$ | 栈空间 $\Theta(d)$ |
| 递归每层保留一个随该层规模增长的数组 | 沿同时活动的调用路径累加各层数组容量 |

**易错点：** C/C++ 中指针变量的大小不能代表其所指向数据的总空间；`sizeof` 不是分析算法辅助空间的通用方法。

## 易错点与考点速查

| 容易误判的说法 | 正确判断 |
| --- | --- |
| 数据项与数据元素是同一层次概念 | 数据项组成数据元素 |
| 数据对象已经规定了元素间结构关系 | 同性质元素的集合不必确定结构关系 |
| 数据结构只需要保存元素值 | 还要表示元素关系 |
| 数据结构三要素是数据、算法、程序 | 三要素是逻辑结构、存储结构、数据运算 |
| 顺序表和链表是两种不同的逻辑结构 | 它们可实现同一种线性表逻辑结构 |
| 双链表有两个方向，所以是非线性结构 | 双向链接不改变线性表的逻辑关系 |
| 动态分配一定得到链式存储 | 动态申请的连续数组也可顺序存储 |
| 链表上的任意插入都只需要常数时间 | 还要看定位结点及检查条件的代价 |
| ADT 必须用 C++ 类实现 | ADT 是逻辑规格，不限定实现语言与形式 |
| 算法必须有输入，而且必须打印结果 | 可无输入；输出可以通过多种方式体现 |
| 算法五个特性包括正确性 | 正确性是设计要求，应与五个特性区分 |
| 有穷性要求算法必须很快 | 它要求有限步骤终止，不等于高效率 |
| 大 $O$ 就是最坏情况 | 大 $O$ 是上界记号，输入情况是另一个维度 |
| $O(n^2)$ 一定比 $O(n)$ 在所有输入上耗时更多 | 渐近阶不保证小规模时的实际耗时排序 |
| 平均复杂度是最好与最坏的平均值 | 平均要根据输入概率求期望 |
| 两层循环一定是平方阶 | 要看次数、重置位置和变量依赖 |
| 对数与指数换底都只影响常数 | 固定对数换底同阶，指数换底一般不同阶 |
| 没有申请数组就只有常数空间 | 递归调用栈也要计算 |
| 递归调用 $2^n$ 次就需要 $2^n$ 栈空间 | 栈空间看同时活动的调用路径 |
| 只用了一个指针，所以一定是常数空间 | 要计入该指针所指的额外存储区 |

## 典型题与作答模板

### 例题一：逻辑结构与存储结构

**题目：** 同一组有先后次序的数据，用数组存储时属于线性结构，用双链表存储时是否变成非线性结构？

**解答：** 不会。线性关系由逻辑次序决定，双链表的前后指针是表示这种关系的存储信息。存储形式改变，没有改变元素间一对一的逻辑关系。

**作答模板：** 先指出研究的是逻辑关系还是存储表示，再说明所给实现是否改变了关系。

### 例题二：基本操作的精确频度

**题目：** 外层 $i=1,\ldots,n$，内层 $j=1,\ldots,i$，内层每次执行一条基本操作，求该操作的次数和时间阶。

**解答：**

$$
C(n)=\sum_{i=1}^{n}i=\frac{n(n+1)}2,\qquad T(n)=\Theta(n^2)
$$

不要与 `CountPairs` 的 $i=0,\ldots,n-1$ 混淆；二者同阶，精确次数不同。

### 例题三：顺序查找的平均代价

**题目：** $n$ 个不同元素，查找必定成功，各位置被查找概率相同。求关键字平均比较次数。

**解答：** 第 $i$ 个位置需要比较 $i$ 次，每个位置概率 $1/n$，所以平均次数为 $(n+1)/2$，平均时间为 $\Theta(n)$。

**若改变条件：** 一旦加入失败事件，应重新写出它的概率与代价，不能继续直接套用成功平均公式。

### 例题四：递归的时间与空间

**题目：** 每次调用递归处理两个规模为 $n-1$ 的子问题，二者依次执行；每层额外工作和局部空间均为常量。求时间与辅助空间。

**解答：** 时间满足 $T(n)=2T(n-1)+\Theta(1)$，是 $\Theta(2^n)$；最大活动调用深度为 $\Theta(n)$，辅助空间为 $\Theta(n)$。

**作答模板：** 时间列递推式或统计展开树；空间写最大深度和每层保留空间。

### 例题五：严格上界与最贴近的阶

**题目：** $T(n)=7n+4$。说它属于 $O(n^2)$ 是否错误？若问最贴近的增长阶应怎样作答？

**解答：** 作为上界，$O(n^2)$ 正确；紧确增长阶是 $\Theta(n)$。常见考试问复杂度时应选择线性阶，而不是故意给出更松的上界。

### 复杂度题统一步骤

1. **确定规模：** 是 $n$，还是需要 $m,n$、$V,E$ 等多个参数？
2. **确认口径：** 精确次数还是阶数；最好、最坏、平均还是特定输入？
3. **选基本操作：** 例如关键字比较、赋值、循环主体。
4. **找重复规律：** 注意循环变量的初值、更新、终止条件及是否重新初始化。
5. **写数学表达式：** 求和、达到阈值的不等式或递推式。
6. **求增长阶：** 保留主导项；需要紧确阶时检查上、下界是否同阶。
7. **另算辅助空间：** 工作区峰值、动态分配和调用栈分别检查。
