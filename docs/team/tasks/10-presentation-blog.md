# 成员 10：PPT、博客与演示

建议分支：`docs/m10-presentation-blog`。主责：`docs/presentation/`；成员资料登记与01协作。

## 具体成果

1. 收集队名、十名成员真实学号/昵称/性格/技术/兴趣/角色、合照和50～100字团队愿景。
2. 按模板完成团队博客，开头有课程/作业链接、目标、队名和学号姓名，标题为“26软工实践 xx 团队展示与选题报告”。
3. 完成约10分钟PPT：真实问题、调研、用户任务、领域资料、Agent流程、样例、真实对比、设计、分工和范围。
4. 录制样例备份，演示暂停提问、输入变化和过程题；录像标注实际版本。
5. 准备6分钟问答：与普通动画网站区别、Agent作用、资料出处、正确性检查、模型失败、全范围如何实现。
6. 22日前完成材料与录屏，23日至24日答辩前只修复、复测和演练修改，25日前团队博客发布并提交；不在此阶段自动向外发布。

## 验收

PPT/博客/需求范围一致；样例与规划明确区分；展示使用真实输出和调研；10分钟内完成演讲；只有团队发布一篇作业博客。
