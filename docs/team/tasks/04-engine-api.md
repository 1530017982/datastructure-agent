# 成员 04：算法引擎、状态与基础接口

建议分支：`feat/m04-binary-search-engine`。主责：`backend/src/algorithms/`、`runs/`、`routes/`、`shared/algorithms/`、server.js业务路由接入。

## 具体实现

1. 实现安全整数升序数组的二分查找；闭区间[left,right]，零起始下标，重复值允许返回任一实际匹配位置。
2. 固定展示代码sourceVersion及稳定lineId，提供C/C++展示实现，与JS执行逻辑逐步核对。
3. 每次初始化、比较、区间变化和结束产生不可变快照。验证输入；不运行学生上传代码。
4. 实现POST创建run、GET完整run、GET指定step。run由服务端保存，查询超范围/不存在返回明确错误。
5. 实现GET题目、POST核对答案：读取06的已核验题目；题目展示不泄露answer，判分不用模型。
6. 支持空数组、负整数、重复值、目标不存在；控制数组长度、输入大小和运行保留时间并更新接口文档。
7. 将Agent路由接到05独立模块；算法与题目接口不依赖模型服务。
