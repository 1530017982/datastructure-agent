## 具体步骤

1. 朴素匹配与 KMP 共用串下标和比较状态。KMP 的 next 与 nextval 放在同一个入口。
2. 括号匹配、转换、求值共用栈视图。表达式有向无环图和关键路径使用 [B 包](b-graphs-engine.md)的图输入约定，并和 02 对齐依赖、当前节点和结果展示。
