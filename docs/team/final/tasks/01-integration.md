# 本轮 01 · 统筹与最终集成

建议分支 `feat/m01-final-integration`。阶段范围与提交规则见[最终任务清单](../README.md)。

## 主责

主持步骤契约对齐，协调公共入口和合并。

## 具体步骤

1. 先与 02 及相关算法负责人确认算法注册、输入输出、步骤快照和视图类型，用现有二分、冒泡验证兼容。
2. 维护最终任务表、公共入口与合并顺序，安排成员交叉复核。
3. 组织每轮联调和冻结，收齐验收证据与问题清单，统一签收。

## 验收

现有二分、冒泡和本机自定义代码回归通过。各算法的负责人、PR 和验收证据可追溯。

- [ ] 用代表项确定算法标识、输入限制、快照结构、源码行映射和视图类型，记录一组可回看的样例。
- [ ] 按批次核对注册、路由和页面入口，跑通一遍「改输入 → 运行 → 单步 → 回看」。
- [ ] 收齐各批次的复核人、PR 与验收证据，复测既有二分、冒泡与本机自定义代码入口。
