# 本轮 02 · 统一动画与播放

建议分支 `feat/final-visualization`。阶段范围与提交规则见[最终任务清单](../README.md)。

## 主责

统一视图、动画与播放，18 分。

## 具体步骤

1. 与 01 和各组负责人用现有数组演示和各组代表轨迹对齐渲染数据。算法负责人给出状态快照、语义事件、标记和说明，02 将这些数据转为画面。
2. 公共工作分六包，各 3 分：数组与代码行联动；链表与栈、队列视图；树与堆视图；图视图；字符串、哈希和矩阵表格的共用视图；播放、回看和跨视图回归。
3. 先用静态样例联调视图，再逐组替换成算法实际生成的轨迹。独有画面优先用共用视图和已有标记组合。

## 验收

单步、暂停、回看、重置和切换算法后，画面与对应快照、代码行一致。用各组代表项录制简短回放并附 PR。

- [ ] 每种共用视图先用一个代表项核对当前元素、节点、边或单元格的标记，以及状态快照和源码高亮是否同步。
- [ ] 接入真实轨迹后，复测暂停、单步前后、回看、重置和切换算法。回看应恢复对应快照。
- [ ] 提交每类已接入视图的录屏或截图、复现样例和仍待联调的事件清单。
